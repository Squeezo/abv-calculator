# abv-calculator

## A simple ABV Calculator for home brewers. 
Check out the demo at [https://brianmccoy.net/abv-calculator](https://brianmccoy.net/abv-calculator)

### Built with React, TypeScript and Vite 

### Development
---

Requires Node 22+ (`.nvmrc` pins 24).

1. Clone this repo.
2. `npm install`
3. `npm start` - dev server
4. `npm test` - Vitest + React Testing Library
5. `npm run build` - type-check and build to `dist/`, served from `/abv-calculator/`
